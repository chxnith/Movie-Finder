# 🎬 Movix

Movix is a responsive movie search web application built with **HTML, CSS, and JavaScript** that allows users to quickly search for movies by simply entering a movie title. The application instantly retrieves and displays comprehensive information about the selected movie through a clean, intuitive, and user-friendly interface.

Whether you're looking for a newly released blockbuster or a timeless classic, Movix provides essential movie details in seconds. Users can explore information such as the movie poster, IMDb rating, genres, release date, runtime, language, plot summary, and other relevant details, making movie discovery simple and enjoyable.

Designed with responsiveness and performance in mind, Movix delivers a seamless browsing experience across desktops, tablets, and mobile devices. The project focuses on creating a modern and visually appealing interface while demonstrating the use of API integration, asynchronous JavaScript, and responsive web design.

> **Note:** Movix is a movie discovery application only. It does **not** support movie streaming or downloading.

---

## ✨ Features

- 🔍 Search movies by title
- 🎬 Display high-quality movie posters
- ⭐ View IMDb ratings
- 🎭 Display movie genres
- 📅 View release dates
- ⏱️ Display runtime
- 🌐 View language information
- 📝 Read movie plot summaries
- 📱 Fully responsive design
- ⚡ Fast and intuitive user experience
- 🔄 Real-time data fetched from a movie database API

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/chxnith/movix.git
```

### Navigate to the Project Folder

```bash
cd movix
```

### Run the Application

Open the `index.html` file in your preferred web browser.

If you're using a movie API that requires an API key, replace the placeholder API key in `script.js` with your own before running the application.
